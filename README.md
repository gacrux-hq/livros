# Edições Gacrux: free book samples

Static site (plain HTML/CSS, no build step) served by GitHub Pages at https://gacrux-hq.github.io/livros/

- One folder per book with `index.html`, the cover, 3 page previews, a share image (`partilhar.jpg`, used for Pinterest/social previews) and the free sample PDF.
- **Amazon links:** edit `links.js` only. Paste each book's Amazon URL between the quotes. While a value is empty, the button shows "coming soon" in the book's language.
- No cookies, analytics or third-party requests. Fonts are self-hosted (SIL OFL, see `assets/fonts/LICENSES.md`).

Samples are free for personal and classroom use. © Edições Gacrux.
